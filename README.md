**TaskOrg** é uma aplicação fullstack para gerenciamento de projetos e tarefas, desenvolvida como projeto de portfólio para demonstrar habilidades em desenvolvimento web moderno. O sistema permite criar projetos, adicionar tarefas, acompanhar progresso e gerenciar status de forma intuitiva.

## Funcionalidades

- Autenticação com JWT (login e registro)
- CRUD completo de projetos
- CRUD completo de tarefas (título, descrição, status)
- Dashboard com métricas em tempo real
- Tema escuro e responsivo
- Ambiente de desenvolvimento com Docker Compose
- Deploy em produção (Vercel + Render + Neon)

### Backend

- React 19
- Vite
- Tailwind CSS
- React Query
- React Router DOM
- Recharts
- Lucide React

### DevOps
- Docker e Docker Compose
- Neon (banco serverless)
